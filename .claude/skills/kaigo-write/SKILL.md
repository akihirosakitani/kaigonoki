# 介護のキ 記事執筆

## 手順

1. **KWの決定**: 引数にKWがあればそれを使う。なければ `content-ops/keywords.md` の「執筆待ち」の先頭行を選び、ステータスを「執筆中」に更新する。
2. **ガイドラインの読込**: `content-ops/editorial-guidelines.md` を必ず読み、仕様(文字数・見出し数・NGワード・出典数)に従う。
3. **リサーチ**: WebSearch で以下を調べる。
   - 対策KWの検索上位記事の構成傾向(網羅すべきトピック、抜けている切り口)
   - 厚労省・公的統計など一次情報(数値の出典として15〜20件)
   - 検索意図を1〜2文で言語化する
4. **構成作成**: h1/h2/h3 の構成案を作り、`content-ops/keywords.md` の該当行のメモ欄に検索意図を追記する。
5. **執筆**: ガイドライン準拠で本文を書く。内部リンク指示は `keywords.md` の既存記事・キュー記事から選ぶ。
6. **パッケージ出力**: `content-ops/articles/<slug>/` に以下を生成する。
   - `meta.json`(形式は `_sample/` 参照。メタディスクリプションは推奨パターンを採用)
   - `article.html`(WordPressに入る本文。h2/h3/p/table/ul/figure)
   - `PACKAGE.md`(タイトル案3本+字数、メタディスクリプション2案、NGワードチェック表、出典リスト、内部リンク指示一覧)
7. **台帳更新とコミット**: `keywords.md` のステータスは「執筆中」のまま(入稿は /kaigo-wp-import の仕事)。パッケージと台帳をコミットし、ブランチにpushする。
8. **報告**: タイトル・文字数・H2/H3数・出典数・スラッグを報告する。Slack接続がある場合は #kaigonoki-claude に「記事生成完了」を通知する(過去の通知フォーマットに合わせる)。

## 禁止事項

- 数値の捏造。確認できない数値は「(※要出典確認)」を付けて参考情報リストに確認先を書く
- NGワード(革命的・画期的・劇的・完璧・最強)の使用
- 既存記事とのKWカニバリ(keywords.md の実績と重複するKWを選ばない)
