# 介護のキ 執筆ガイドライン

過去の納品記事(「介護福祉士 やめとけ」9,566字・出典20件 等)の品質基準を明文化したもの。`/kaigo-write` はこのルールに必ず従う。

## メディアの前提

- 媒体: 介護のキ(kaigonoki.com)。介護職で働く人・介護職への転職検討者・家族介護をする人が読者
- トーン: 読者のしんどさにまず共感し、断定で追い詰めず、現実的な選択肢を両面提示する
- 専門的すぎる表現は噛み砕く。専門用語には一言説明を添える

## 記事仕様

| 項目 | 基準 |
|---|---|
| 文字数 | 6,000〜10,000字(検索意図の重さに応じて) |
| 見出し | H2: 5〜7個 / H3: 12〜20個。h1はタイトルと同一 |
| タイトル | 30〜40字、主KWを含める。3案作成し、推奨案を明示 |
| メタディスクリプション | 118〜120字を2パターン。主KWを含める |
| スラッグ | 英小文字とハイフン(例: `kaigoshoku-bonus`) |
| 出典 | 15〜20件。厚労省・公的統計を優先。数値には出典を紐づける |
| 内部リンク | 関連する既存・計画中記事への内部リンク指示を3件以上(`※内部リンク:` 形式) |
| FAQ | 検索意図に「不安・疑問」が含まれるKWでは記事末尾にFAQを2〜4問 |
| まとめ | 最終H2は「まとめ」。要点を3〜5文で再掲 |

## 構成の作法

- 導入は読者の悩みの言語化(「〜と悩んでいませんか」)→ 記事で得られることの明示 → 目次
- ネガティブ系KW(きつい・辞めたい・やめとけ 等)は、ネガティブ要素で終わらせず「仕事内容・メリット・対処法」をセットで提示して離脱を防ぐ
- HowTo系は見出しに数字を入れる(「〜10選」「3ステップ」)
- 比較・分類は表を使う(施設形態別、資格ルート別 など)
- 体験談・具体例を最低1つ入れる(介護現場ならではの場面: 夜勤明け、入浴介助後 など)

## NGワード

以下は使用禁止。使いそうになったら代替表現に置き換え、パッケージのチェック表に記録する。

| NGワード | 代替案 |
|---|---|
| 革命的 | 新しい視点の、注目の |
| 画期的 | 注目されている、有効な |
| 劇的 | 大きく、著しく |
| 完璧 | 十分な、万全に、整った |
| 最強 | 特に有力な、おすすめの、効果的な |

## 表現・コンプライアンス

- 医療・制度・金額の数値は「(※要出典確認)」を付け、参考情報リストに確認先を明記する
- 適性・診断系は断定を避ける(「向いていない」→「合いにくい傾向」)
- 読者の自己効力感を下げない。年齢・経験への不安には現実的な注意点とセットで前向きな根拠を示す
- 誇大表現・不安を煽る表現・特定施設や事業者の誹謗は禁止

## 納品パッケージ(articles/<slug>/ の中身)

1. `meta.json` — タイトル(推奨案)・スラッグ・メタディスクリプション・カテゴリ・タグ
2. `article.html` — 本文全文(h2/h3/p/table/ul。インフォグラフィック挿入位置に `{{INFOGRAPHIC_URL}}`)
3. `PACKAGE.md` — タイトル案3本(字数付き)、メタディスクリプション2案、NGワードチェック表、出典リスト、内部リンク指示一覧
4. 画像(`eyecatch.png` / `infographic.png`)は生成できる環境の場合のみ。なければ Slack 通知に「画像未添付」と明記
